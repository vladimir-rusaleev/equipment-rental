# Rent — прокат строительного инструмента

Каталог инструментов с поиском, категориями и проверкой доступности на даты.
Gateway отдаёт веб-интерфейс и запрашивает каталог у Inventory по gRPC.
Демонстрационный каталог хранится в памяти.

## Запуск

Нужен Go 1.27.1+.

```bash
cp .env.example .env
make run
```

Откройте [localhost:8080](http://localhost:8080/).
