# Rent — прокат строительного инструмента

Inventory хранит каталог и экземпляры инструмента в памяти. Через gRPC
можно получить список моделей и проверить доступность на даты.
При запуске создаётся демонстрационный каталог.

## Запуск

Нужен Go 1.27.1+.

```bash
cp .env.example .env
make run
```

Inventory слушает порт `50052`. Контракт находится в
`api/rent/v1/rent.proto`. Для запросов передайте ключ из `.env` в метаданных
`x-service-key`.

```bash
make test
```
