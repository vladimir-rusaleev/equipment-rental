# Rent — прокат строительного инструмента

Каталог, корзина и бронирование для одного пункта проката. Сотрудники
оформляют выдачу и возврат через панель проката.

Данные сохраняются в PostgreSQL. Уведомления передаются по gRPC
и выводятся в лог.

## Запуск

Нужны Go 1.27.1+ и Docker Compose.

```bash
cp .env.example .env
make db-up
make run
```

Интерфейс доступен на [localhost:8080](http://localhost:8080/).
Для входа администратором используйте почту и пароль из `.env`.
Для запуска без PostgreSQL используйте `make run-memory`.
Сквозная проверка четырёх сервисов — `make smoke`.

Тесты PostgreSQL запускаются командой `make test-postgres`.
