# Frontend

`frontend/static/` — отдельный слой интерфейса: HTML, CSS и JavaScript-модуль без
внешних runtime-зависимостей и без Node-сервера. `frontend/assets.go` встраивает файлы
в бинарник Gateway через `go:embed`; они доступны и в Docker-образе.
После изменения файлов интерфейса нужно пересобрать и перезапустить Gateway (`make run`).

Браузер обращается только к относительным `/api/v1/...` на том же адресе. Поэтому
CORS и отдельный gRPC-прокси не нужны. Gateway переводит запросы в gRPC.

Реализованы:

- каталог, поиск/категории, выбор дат и календарь свободного количества;
- карточка инструмента, предварительная стоимость, корзина с датами каждой позиции;
- гостевая корзина в браузере, перенос её содержимого в аккаунт при входе;
- регистрация, вход, выход, личные заказы и отмена до выдачи;
- автообновление заказов в промежуточных состояниях;
- панель сотрудников: все заказы, выдача, выбор экземпляров для частичного возврата;
- управление моделями/тарифами/URL изображения (admin), экземплярами и их состоянием;
- назначение ролей по ID пользователя (admin).

Сессия сохраняется в localStorage этого браузера. Выход удаляет токен из браузера;
серверный logout пока отсутствует, токен истекает через 24 часа. Пароли не сохраняются.
Все права повторно проверяет backend: скрытие кнопок в интерфейсе не заменяет авторизацию.
Полный ID клиента для назначения роли виден сотрудникам в заказе; отдельного поиска
пользователей в API пока нет.

Предварительная стоимость корзины основана на текущем каталоге. Окончательная стоимость
фиксируется backend при бронировании. Для демонстрационных моделей без фотографий
используются встроенные SVG-иллюстрации. Внешние изображения допускаются только по HTTPS.
