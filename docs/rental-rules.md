# Правила аренды

- Модель инструмента и физический экземпляр — разные сущности.
- У каждой позиции корзины свои даты и количество.
- Даты — `YYYY-MM-DD`, период полуоткрытый: `[start, end)`. Например,
  10–12 ноября — двое суток; следующая аренда может начинаться 12 ноября.
- Максимум 50 позиций, до 100 экземпляров в позиции и до 366 суток на период.
- Деньги — целые копейки, валюта первой версии — RUB. `150000` = 1500 рублей.
- Цена позиции: суточный тариф × число суток × количество. Тариф и название
  фиксируются при успешном резервировании; изменение каталога не меняет заказ.
- Корзина не резервирует оборудование. Календарь также не гарантирует бронь.
- Inventory резервирует весь комплект атомарно (транзакция PostgreSQL, в памяти — mutex): либо все позиции,
  либо ни одной. Учитываются другие позиции этого же комплекта.
- `request_id` checkout принадлежит попытке оформления: повтор с тем же ключом
  возвращает тот же заказ, даже если корзина уже изменилась. Новая попытка — новый ключ.
- Выдача в первой версии выполняется для заказа целиком. Возврат возможен по
  отдельным экземплярам. После возврата всех экземпляров заказ завершён.
- Возврат раньше срока пока не сокращает занятый интервал и не пересчитывает цену.
- Выдача проверяет физическую доступность: экземпляр, не возвращённый по предыдущему
  заказу, выдать нельзя. Просроченные выданные экземпляры исключаются из новой доступности.
- Обслуживание/списание экземпляра с незавершёнными резервами запрещено: сначала
  сотрудник должен разрешить связанные заказы. Плановые интервалы обслуживания пока не реализованы.
- Отмена разрешена до выдачи. Для отмены чужой брони сотрудник указывает причину.
- Продление, залоги, реальные платежи, фотографии как загружаемые файлы и доставка
  пока не реализованы. Каталог принимает URL изображений.

Календарь показывает свободное количество **на каждый день**. Для многодневного
периода окончательная проверка учитывает одни и те же физические экземпляры
на всём интервале; дневные количества не заменяют эту проверку.
